# Relevé M130

Relevé de plan de maison avec un télémètre laser Bluetooth iRULER M130.

- Ouvrir l'app : https://tibodevc.github.io/releve-m130/
- Sur iPhone : ouvrir le lien dans le navigateur **Bluefy** (Safari ne gère pas le Bluetooth web).
- Sur Mac : Chrome, ou Brave avec le Bluetooth web activé.

Les relevés restent dans le navigateur ; « Exporter le relevé » produit un fichier JSON.
